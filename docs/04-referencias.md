4. Referências

Este capítulo apresenta os materiais utilizados como referência e apoio para a elaboração deste guia.

Linguagem C

A linguagem C possui uma documentação ampla e é utilizada como referência para o estudo de fundamentos de programação.

Durante o desenvolvimento dos exemplos deste guia, foram considerados conceitos básicos da linguagem, como:

- Variáveis;
- Tipos de dados;
- Entrada e saída;
- Operadores;
- Estruturas condicionais;
- Estruturas de repetição.

Materiais de estudo

Documentação da linguagem C

A documentação da linguagem C pode ser utilizada para consultar funções, tipos de dados, operadores e outros recursos da linguagem.

Recomendação de estudo:

- Consultar a documentação quando surgir uma dúvida sobre uma função;
- Observar a sintaxe correta;
- Verificar exemplos de utilização;
- Testar os exemplos em um ambiente de desenvolvimento.

Livro de apoio

FORBELONI, André Luiz Villar. Lógica de Programação: a Construção de Algoritmos e Estrutura de Dados.

O livro apresenta conceitos relacionados à lógica de programação, construção de algoritmos e estruturas utilizadas na resolução de problemas.

Git e GitHub

Git é um sistema de controle de versão utilizado para acompanhar alterações realizadas em arquivos durante o desenvolvimento de um projeto.

GitHub é uma plataforma que permite hospedar repositórios Git e facilita atividades como colaboração, revisão de código e publicação de projetos.

Durante este projeto foram utilizados conceitos como:

- Repositório;
- Commit;
- Branch;
- Merge;
- Pull Request;
- Resolução de conflitos;
- Histórico de alterações.

Como utilizar as referências

As referências devem ser utilizadas como materiais de apoio.

Ao encontrar uma dúvida durante os exercícios, o estudante pode consultar a documentação ou outro material de estudo para compreender o conceito e depois aplicar o conhecimento em um novo exemplo.

O objetivo não é apenas copiar uma solução, mas compreender o funcionamento do código.

Considerações sobre as fontes

Este guia possui finalidade educacional e introdutória.

Os exemplos foram elaborados para facilitar a compreensão dos conceitos básicos de programação em C. Para aprofundar os conhecimentos, recomenda-se consultar documentação técnica e materiais específicos sobre a linguagem.
