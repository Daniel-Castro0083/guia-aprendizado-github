Aprendizados do Projeto

Introdução

O desenvolvimento deste projeto permitiu colocar em prática conhecimentos relacionados à lógica de programação, à linguagem C, ao Markdown e ao uso do Git e GitHub.

A construção do guia também possibilitou compreender melhor a importância da organização e do versionamento durante o desenvolvimento de um projeto.

Aprendizados sobre lógica de programação

Durante a elaboração do material, foram revisados conceitos fundamentais de lógica de programação, como variáveis, tipos de dados, entrada e saída de informações, operadores, estruturas condicionais e estruturas de repetição.

Um dos principais aprendizados foi perceber que a programação envolve mais do que escrever comandos. Antes de desenvolver um programa, é necessário compreender o problema e organizar uma sequência de passos para chegar a uma solução.

Aprendizados sobre C

A produção dos exemplos permitiu praticar conceitos básicos da linguagem C.

Entre os principais conceitos trabalhados estão:

- Declaração de variáveis;
- Tipos de dados;
- Entrada de dados com "scanf()";
- Saída de dados com "printf()";
- Operadores aritméticos;
- Operadores relacionais;
- Operadores lógicos;
- Estruturas condicionais;
- Estrutura "switch";
- Estrutura "while";
- Estrutura "for".

A realização dos exercícios também mostrou a importância de testar os programas e analisar os resultados apresentados.

Aprendizados sobre Git

O projeto também permitiu praticar o uso do Git como sistema de controle de versão.

Foram utilizados conceitos como:

- Criação de repositório;
- Commits;
- Branches;
- Staging;
- Histórico de alterações;
- Merge;
- Resolução de conflitos.

Uma prática importante aprendida foi realizar commits pequenos e relacionados a uma alteração específica. Isso facilita a compreensão do histórico e permite identificar com mais facilidade o que foi alterado em cada etapa.

Aprendizados sobre GitHub

O GitHub complementa o uso do Git ao permitir armazenar o projeto remotamente e facilitar a colaboração.

Durante o projeto, foram estudados conceitos relacionados a:

- Repositórios remotos;
- "origin";
- "push";
- Pull Requests;
- Revisão de alterações;
- Integração de branches.

A utilização desses recursos demonstra como um projeto pode ser desenvolvido de maneira organizada e colaborativa.

Aprendizados sobre conflitos

Outro aprendizado importante foi compreender que conflitos podem ocorrer quando diferentes alterações são realizadas sobre uma mesma parte de um arquivo.

A resolução de um conflito exige analisar as versões envolvidas, escolher ou combinar as alterações corretas, remover os marcadores de conflito e depois registrar a resolução no Git.

Esse processo mostrou a importância de revisar cuidadosamente o conteúdo antes de realizar um merge.

Reflexão final

O projeto contribuiu para desenvolver conhecimentos técnicos e também uma visão mais organizada sobre o processo de desenvolvimento de software.

A combinação entre programação, documentação e controle de versão mostrou que um projeto não é formado apenas pelo código. A organização dos arquivos, a descrição das decisões, o histórico de alterações e a documentação também fazem parte do desenvolvimento.

Como próximo passo, pretendo continuar praticando programação em C, desenvolver programas mais completos e utilizar Git e GitHub em novos projetos para consolidar os conhecimentos adquiridos.
